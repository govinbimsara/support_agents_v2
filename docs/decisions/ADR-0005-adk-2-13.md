# ADR-0005: Agent framework: ADK 2.13.x
- Status: Accepted (seeded from SRS v0.2 Appendix A)
- Date: 2026-11-14
- Requirements: SDD 25.1

## Context
Options were considered during design and replaced; recorded so they are not reintroduced by mistake.
Documented: ADK 1.18 (v1) and >= 1.22.1 were superseded by 2.13.x; the pin is shared by chat API and voice worker images (SDD 25.1).

Likely reasons (confirm): ADK 2.x graph workflows are required for troubleshooting flows (FR-TS) and LiveKitRunner support; pinning avoids drift.

## Decision
ADK 2.13.x, pinned once and shared by the chat API and voice worker images.

## Alternatives considered (superseded)
ADK 1.18 (v1) / >= 1.22.1

## Consequences
Revisit when the related spikes report back (docs/spikes/STATUS.md).
