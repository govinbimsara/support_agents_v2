# ADR-0012: Voice refusals and clips: Live speaks the refusal; operator script + S3 manifest
- Status: Accepted (seeded from SRS v0.2 Appendix A)
- Date: 2026-11-14
- Requirements: SDD 3.1, 20 rows 10, 16

## Context
Options were considered during design and replaced; recorded so they are not reintroduced by mistake.
Documented: Live speaks the exact refusal; a pre-recorded clip is the fallback (FR-GR-04, SDD 20 rows 10 and 16).

Likely reasons (confirm): all-recorded refusals cannot adapt to context and need three language assets per clip; a portal clips page/table was dropped for a simple operator script plus S3 manifest.

## Decision
Live speaks the refusal with a clip as fallback; clips generated by an operator script (/ops/clips) with an S3 manifest.

## Alternatives considered (superseded)
All refusals pre-recorded; voice clips page in portal; voice.clips table

## Consequences
Revisit when the related spikes report back (docs/spikes/STATUS.md).
